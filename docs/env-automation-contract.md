**Override rule:** `cleaner.sh` reads the environment before parsing CLI flags. Value mirrors (`CONFIG`, `LOG`, `RISK`, `EXCLUDE`, `ONLY_TARGET`, `EXCLUDE_TARGET`, `ONLY_PATH`, `EXCLUDE_PATH`, `MIN_RECLAIM`, `MIN_FREE`, `MIN_AGE`, `ACTION_TIMEOUT`, `TRASH_KEEP_DAYS`, `LOCK_WAIT`) are replaced by their CLI flag (`METRICS_FILE` and `PREVIEW_METRICS_FILE` are env-only, with no CLI flag). On/off mirrors (`QUIET`, `DEBUG`, `NOTIFY`, `FAIL_FAST`, `JSON`, `TRASH`, `FORCE`, `YES_DANGER`) can only be switched on from the CLI — no flag switches them off — so disable one for a single run by setting it to a non-truthy value (for example `LINUX_CLEANER_TRASH=0 cleaner --clean`) or unsetting it. For `FORCE`, an explicit `--dry-run` still restores preview mode. `ALLOW_OUTSIDE_HOME` is a deprecated no-op; the flag and the variable together print at most one warning.

**Flagged divergence rows:** none — truthy lists, the JSON dry-run requirement, and the value/on-off override split match across `docs/cli-reference.md` and `cleaner.1`.
